 Titanic Exploratory Data Analysis:

This repository contains a short, reproducible EDA notebook on the Titanic dataset — the classic "hello world" of data science.

The notebook runs end-to-end after a fresh kernel restart and demonstrates clear data cleaning, exploration, and storytelling.

Contents:

- `requirements.txt` → pinned versions of pandas, numpy, matplotlib, seaborn
- `data/titanic.csv` → dataset (relative path, not hardcoded)
- `notebook.ipynb` containing:
  - Data loading
  - Cleaning decisions (with comments)
  - Exploratory plots
  - 150-word Findings section

 Goal:

Not to build a predictive model, but to show clear thinking, reproducible workflow, and readable code.

By the end, an interviewer can understand in two minutes:
- What was done
- What was found
- What could be done next
